# evalseal (Python)

Python parity library for the EvalSeal `evalseal/1` protocol: canonical
hashing, Ed25519 signed envelopes, deterministic grading, evidence validation,
audit-chain verification, attestation-pack building/verification, the local
reference authority/service, and the `python -m evalseal` CLI.

See the repository `README.md` for the full contract and scope limits.
